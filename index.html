Python Simulation • Club Selection Project

WALL-E and EVE's Signal (Autonomous Grid Explorer)

An autonomous robot simulation developed for the VinnovateIT technical club selection. In a 5×5 discrete grid world, WALL-E receives distance clues to eliminate impossible target coordinates, uses BFS to find shortest obstacle-free routes, and monitors battery consumption.

Verified Technical Implementation:

  • Smart Search: Narrows down candidate coordinates using Manhattan distance calculations against received clues.
  • Breadth-First Search (BFS): Explores cardinal neighbors to calculate shortest paths around static obstacles.
  • Battery-Aware Logic: Evaluates step cost to the charging station before committing to further exploration.
  • Encapsulation: Separates environment state from agent perception so the agent cannot cheat.
  • Logging & Testing: Generates action_log.json and final_report.json, with built-in --test flags.
