Website Change Detector

A real-time website monitoring and content audit application engineered with Python, Flask, SQLite, and BeautifulSoup4. Periodically scrapes target web pages, hashes extracted text with SHA-256 to avoid noisy false alarms, visualizes line-by-line differences using unified diff syntax, and enforces strict SSRF security boundaries.

Verified Technical Implementation:

  • BeautifulSoup4 Extraction: Parses raw HTML into clean textual strings, discarding irrelevant markup noise and dynamic script tokens.
  • SHA-256 Fingerprinting: Computes cryptographic hash checksums of parsed content to detect true modifications immediately.
  • Unified Visual Diff Viewer: Color-coded terminal display highlighting added lines (green), removed lines (red), and untouched context.
  • SSRF Security Layer: Robust URL validation blocking loopback (127.0.0.1), private RFC-1918 subnets, and unsupported protocol schemes.
  • Audit Trail & On-Demand Scanning: SQLite database maintaining historical change snapshots with one-click manual re-scan capability.
